## Animation Flow

### Switching from English to Bangla
```
Step 1: User clicks [🌐 বাং] button
        ↓
Step 2: Language changes to 'bn'
        ↓
Step 3: All text updates instantly
        ↓
Step 4: Button now shows [🌐 EN]
        ↓
Step 5: Bangla font loads (if not cached)
        ↓
Step 6: Layout adjusts (if needed)
        ↓
Step 7: Choice saved to localStorage
```

### Switching from Bangla to English
```
Step 1: User clicks [🌐 EN] button
        ↓
Step 2: Language changes to 'en'
        ↓
Step 3: All text updates instantly
        ↓
Step 4: Button now shows [🌐 বাং]
        ↓
Step 5: English font loads
        ↓
Step 6: Layout adjusts (if needed)
        ↓
Step 7: Choice saved to localStorage
```
